\ChEightStarSection{Supplementary Material}


This supplement provides additional methodological details and analyses.
Unless otherwise stated, analyses use the event-matching threshold of 0.1 and the event definitions and temporal metrics described in the main manuscript.
Higher concordance and AULTC indicate better temporal performance.
Calculations use unrounded values and displayed metric values are rounded to two decimal places.
