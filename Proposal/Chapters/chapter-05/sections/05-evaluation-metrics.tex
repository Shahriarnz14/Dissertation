\subsubsection{Evaluation Metrics}
\label{ch05:sec:evaluation-metrics}

\label{ch06:sec:evaluation_methodology_metrics}

\ChFiveParagraph{Event match recall, precision, and F1}

To evaluate alignment between predicted and reference clinical events, we applied a recursive best-match strategy adapted from prior work \citep{wang2025large,pmlr-v333-noroozizadeh26a}, as summarized in Algorithm~\ref{ch05:alg:recursive_match}.
At each iteration, the method selects the closest unmatched predicted--reference pair under a text-similarity metric, retains the match if it falls below a distance threshold, and removes both events before continuing.
This procedure yields an efficient one-to-one alignment that accommodates timelines of unequal length.

We evaluate event identification using event match recall, precision, and F1.
Precision therefore penalizes additional model-generated events that remain unmatched under the one-to-one alignment, complementing recall, which measures the proportion of reference events recovered.

As a sensitivity analysis, we also evaluated a globally optimal one-to-one alignment based on the Linear Assignment Problem (LAPJV) \citep{jonker1987shortest}.

We therefore report results using the recursive matching strategy in the main text and provide full LAPJV details and comparison tables in the Supplementary Material (Section~\ref{ch05:apd:lapjv-matching}).

\ChFiveParagraph{Temporal metrics}

We used 2 metrics which evaluate how well the LLM extracts timestamps of clinical events: (a) \textbf{\emph{Temporal concordance}} (c-index) evaluates whether the relative ordering of event times in the model output agrees with the reference timelines, providing an order-based summary of temporal consistency. (b) \textbf{\emph{Log-time discrepancy}} quantifies the log transform of the absolute timestamp difference for matched events, and we summarized its distribution using the Area Under the Log-Time CDF (AULTC), which captures the cumulative proportion of events achieving small timing errors. \ChFiveRebuttal{
AULTC is computed over semantically matched event pairs only and therefore measures timestamp accuracy conditional on successful event alignment. Unmatched events do not enter the empirical CDF or AULTC and are evaluated separately by the event-extraction metrics. 
}

Concordance is also evaluated only on successfully matched events with usable timestamps; high temporal accuracy does not necessarily imply high event recovery.

\textbf{Median absolute error (MAE)}: Median time discrepancy (in hours) among matched events.

The common metric definitions, including concordance tie handling and AULTC normalization, are given in Appendix~\ref{ch05:apd:evaluation-metrics}.

Study-specific aggregation and uncertainty conventions are retained with the corresponding results.

The historical term \emph{event match rate} in the unchanged figures denotes event match recall.
